## About Me
I’m Balasubramanian Mahadevan, a Senior Technical Writer with 13+ years of experience creating structured, reusable documentation for SaaS, HR, payroll, finance, and integration platforms. I specialize in information architecture, taxonomy, metadata strategy, and modular content design—turning complex system behavior into clear, scalable content.

I’ve built documentation systems using Oxygen XML, Paligo, GitHub-based workflows, and CCMS platforms, and I work closely with Product, Engineering, UX, QA, and Support to ensure content aligns with real system behavior. My experience spans release notes, API docs, workflow diagrams, SOPs, onboarding content, and persona-based help systems.

During a recent career break, I expanded my technical toolkit—learning GitHub repo management, Git Bash workflows, Figma, and beginner-level C#. I’m also pursuing Spanish through Instituto Cervantes, driven by my interest in languages and cross-cultural communication.

I care deeply about clarity, structure, and usability. My goal is simple: create documentation that helps users understand systems without friction.
